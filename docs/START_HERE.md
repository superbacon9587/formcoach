# The first five minutes

1. Assign A/B/C. A opens docs/BOOTSTRAP.md and creates ONE shared initial main.
2. B/C install tools meanwhile, then clone that repo after A says main is ready.
3. Each reads AGENTS.md + docs/CONTRACT.md + their PERSON_A/B/C.md guide.
4. Everyone runs npm ci and npm run dev. Mock preview is the shared baseline.
5. Each starts the prescribed feature branch and gives their AI the role prompt.

The starter is intentionally incomplete: no camera inference and no assessment
until A/B implement their entry points. It is a stable shared starting point.
The synthetic skeleton is a development fixture, not your instructional animation.

Integration target: first real set reaches summary by elapsed hour 2.
No new core features after elapsed hour 6. Use last 2 hours to test and submit.
